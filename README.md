# euzoia-crete

Διαδραστικοί οδηγοί για ασθενείς της μελέτης «Ευζωία» (www.euzoia-crete.gr), δημοσιευμένοι μέσω GitHub Pages.

- `diatrofi/` — Διατροφή
- `kinisi/` — Φυσική δραστηριότητα
- `ypnos/` — Ύπνος
- `kapnisma/` — Διακοπή καπνίσματος

Μόνο εκπαιδευτικό υλικό. Ποτέ δεδομένα συμμετεχόντων σε αυτό το αποθετήριο.
